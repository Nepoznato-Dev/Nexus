## 📝 Sound Quality Guidelines

- **Format:** MP3 or OGG (browser compatible)
- **Bitrate:** 128-192 kbps (good quality, reasonable size)
- **Sample Rate:** 44.1 kHz standard (CD quality)
- **File Size:** Keep under 500KB per sound
- **Duration:** 3-10 seconds for startup/shutdown

## 🔍 Where to Find Sounds

### Official Sources
1. **Archive.org Software Preservation** - Historical OS distributions
2. **WinWorldPC** - Vintage software preservation
3. **Abandoned Ware Sites** - Abandonedware.org and similar
4. **Internet Archive** - Wayback Machine + old installations
5. **GitHub Repositories** - Retro OS sound collections

### Extraction Methods
1. **Install in VM** - Install old OS in VirtualBox/QEMU, record startup
2. **Extract from Media** - Use 7-Zip or WinRAR to extract installer files
3. **YouTube Compilations** - Download high-quality compilations with permission
4. **Audio Editing** - Isolate clean segments from recorded bootup videos
5. **Official Resources** - Some vendors released official sound packs

### Specific Resources
- **Windows:** Extract from `C:\Windows\Media\` folder
- **macOS:** Extract from `/System/Library/Sounds/` folder
- **Linux:** Extract from `/usr/share/sounds/` directories

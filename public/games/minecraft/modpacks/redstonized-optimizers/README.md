## 🎯 Installation

### Automatic (Recommended)

1. Launch Nexus
2. Navigate to Minecraft section
3. Select your Minecraft version
4. Check "Install Redstonized Optimizers"
5. Click "Launch"

The modpack will be automatically installed with all dependencies!

### Manual Installation

1. Install Fabric Loader for your Minecraft version
2. Download the modpack from the releases
3. Extract to `.minecraft/mods/`
4. Launch Minecraft with Fabric profile

## 🔧 Known Issues & Fixes

### Compatibility Issues

**Issue:** Some mods conflict with each other
**Fix:** Use the in-game mod toggle to disable conflicting mods

**Issue:** Shaders cause FPS drops
**Fix:** Try lighter shader packs or disable Distant Horizons

**Issue:** Distant Horizons stuttering
**Fix:** Reduce LOD quality in Distant Horizons settings

### Common Fixes

1. **Low FPS despite mods?**
   - Allocate more RAM (8-16GB recommended)
   - Update graphics drivers
   - Disable unnecessary mods in Mod Menu

2. **Mods not loading?**
   - Ensure Fabric API is installed
   - Check Minecraft version matches mod versions
   - Remove incompatible mods

3. **Crashes on startup?**
   - Check crash reports for conflicting mods
   - Update Fabric Loader
   - Disable mods one by one to find culprit

## PART 1 — WHAT NEXUS IS

Nexus is a web-based OS-style platform built for students. It is not a website. It behaves like a controlled desktop environment running inside a browser — closer to ChromeOS or Linux than to any web app.

**Core promise:** "The user is the provider. RAZONET exists to serve them, not observe them."

**Who uses it:** ~15–30 users. Mostly school friends on Chromebooks (Bandera ISD, Mon–Thu 7:55 AM–4:16 PM). Some users on home setups including high-refresh monitors (up to 165Hz).

**What it contains:**
- RAZONET — the AI assistant and primary intelligence layer
- Hydrux — 167+ games library
- In-app browser (iframe + search proxy)
- File manager
- Terminal
- Task manager
- Media player (movies, music)
- Study tools (flashcards, notes, Pomodoro, calculator, dictionary, formula sheet)
- Tab cloaking / stealth / boss key system
- UI editor (FancyMenu-style drag/drop)
- Admin dashboard (Watchtower)
- Discord integration

## PART 2 — CORE PHILOSOPHY (NON-NEGOTIABLE)

These rules override everything. No feature, no convenience shortcut, no "just this once" breaks them.

1. **Performance over visuals.** When constrained, drop effects first — never drop responsiveness.
2. **Recovery over prevention.** Everything reversible. Safe Mode always loads, always works.
3. **User control over automation.** RAZONET suggests. It never decides without consent.
4. **No interruptions during games.** Hard rule. No popups, no AI prompts, no sounds during gameplay.
5. **Local-first.** Nexus functions without backend. Backend is support infrastructure, not the brain.
6. **Nothing breaks silently.** Every failure is logged, explained, and recoverable.
7. **No creepy AI behavior.** RAZONET has no gender, no emotional dependency, no roleplay.
8. **No secrets in frontend.** API keys, peppers, service keys live only in Cloudflare Worker env vars.
9. **Users are the provider.** Data belongs to the user. RAZONET serves them, not observes them.

### What Each Role Can Do

**Guest**
- Demo access: limited features, simple games, YouTube (embedded), basic cosmetic UI changes (non-persistent)
- No Safe Mode, no saving, no uploads, no scripts, no backend-heavy features
- Everything resets on refresh

**Member**
- Core Nexus features, RAZONET with limited memory, personal dashboard + persistent settings
- Study tools, browser-lite, widgets, safe sandboxed scripts
- Safe Mode via Shift+Login only
- Cannot: upload public games, generate access codes, moderate anyone

**Member+**
- Everything Member has
- Upload and share games publicly
- Advanced UI editor
- Performance overrides (FPS targets, task priority)
- Extended RAZONET customization
- Can enter Safe Mode from inside app anytime

How to get Member+: Supporting Nexus, or manual approval by Owner or Admin.

**Moderator**
- Everything Member+ has
- Kick (force logout, requires re-login)
- Temporary bans: 5 minutes to 24 hours max — no permanent bans
- View reports and read-only logs
- CANNOT: permanently ban, generate access codes, change roles, act on Admins or Owner
- All actions logged with cooldowns; abuse auto-locks tools

How to get Moderator: Manual permission only (must already be Member+).

**Admin**
- Everything Moderator has
- Permanent bans
- Role assignment up to Moderator level
- Generate access codes
- Early feature access
- Advanced diagnostics and feature flag toggles
- CANNOT: grant Admin role, demote Owner, disable safety core

How to get Admin: Owner only. Closest friends only.

**Owner**
- Everything, no exceptions
- Override all bans
- Assign and revoke Admin
- Emergency controls and kill switches
- Full logs (Owner actions logged but never blocked)

### Role Locking (Punishment System)

Owner and Admin can lock a user to a lower role for bad behavior.

Valid reasons:
- Flaunting Nexus as if it's theirs
- Bad behavior in the Nexus Discord
- Breaking Nexus rules

Lock types:
- **Soft Lock (Probation):** Keeps current role, disables advanced features temporarily
- **Hard Lock (Forced Downgrade):** Forced to lower role, promotion blocked
- **Permanent Lock:** Stays at locked role until Owner removes it

Rules:
- No one can lock someone above their own role
- Lock overrides all promotions including Discord role sync
- Locked state persists even if user relinks Discord
- Every lock is logged: who, when, duration, reason

UI copy (non-hostile, non-accusatory):
> "Some features are temporarily unavailable. This restriction expires in 3 days."

### Access Codes

- Admins and Owner can generate access codes
- Owner is the only one who can generate Admin verification codes
- Codes are: one-time use, expirable, uppercase with 1-2 symbols, server-validated
- Only hashes are stored — never the plain code

### Discord + Role Gating

- Discord is optional to use Nexus
- Discord is required to go above Member unless Owner grants an exception
- Some friends do not have Discord (overprotective parents) — Owner exception covers this
- If banned in Discord, Nexus applies a role lock — not a full ban, severity-mapped
- Unlinking Discord does NOT remove the lock; locks belong to the Nexus account
- Once a Discord ID has ever been linked, that record is permanent

Discord ban severity mapping:
- Minor (spam, mild violation): Nexus feature lock for hours
- Medium (harassment, repeated): lock to Guest/Restricted for days
- Severe (threats, raids): full Nexus ban — Owner/Admin only

RAZONET is completely custom-built — not based on Llama, Qwen, Phi, Mistral, or any other foundation model. Every behavior, personality trait, and reasoning pattern is designed from scratch.

Core principle RAZONET follows:
> "The user is right until RAZONET can prove otherwise — and proof requires evidence, not just training data."

### AUTO Mode — Complexity Scoring Rubric

AUTO Mode scores the incoming task to determine which tier to run:

| Signal | Points |
|---|---|
| Per 1,000 input tokens | +1 |

| Domain: code or math | +2 |
| Domain: multi-domain | +3 |

| Ghost-Archive hit (context found) | -1 |

Score to RDL mapping:
- 0-4: Rzr 1 (RDL 1)
- 5-8: Rzr 2 (RDL 1.5)
- 9-14: RAZONET (RDL 2)
- 15-19: Vexon 2 (RDL 3)
- 20+: Noxyn 1 / Noxyn 2 (RDL 4-5)

Three hardware override rules:
1. **Hardware Handshake Floor** — caps at what the machine can actually handle
2. **Stability Lock Ceiling** — once pressure-demoted mid-task, cannot re-promote for that task's lifetime
3. **Ghost-Archive Fast Path** — if same task type succeeded at lower RDL 3+ times, caps at RDL 2 max

Mode suggestion language: always natural, never technical. Never say "Plan Mode." Say "Want me to map this out first?" or "I can take this end to end if you want." Tier names never reach the user.

### RAZONET Core Architecture

**F.L.U.X.** (Fast Logic & URL eXtraction) — External specialist

- Scrapes URLs locally, Cloudflare Workers as fallback
- Shadow DOM 5000px scroll simulation for JS-heavy sites
- Content Quality Validator (CQV) tags: CLEAN / DEGRADED / POISONED
- Edge case handling: paywalls (honest fallback + user paste), dead links (fail fast to Wayback Machine), rate limiting (exponential backoff to CF Worker), stale content (always timestamp, warn on >90 days for time-sensitive topics)
- FLUX never leaves RAZONET empty-handed: primary fails → alternative retrieval → alternative source → use available with honest context → tell user clearly what happened

**S5 (The Sentinel)** — Security chokepoint between FLUX and RAZONET

- Adversarial sanitization on all external data
- Standalone infrastructure component, never a S-Squad member
- Web content is never allowed to become instructions or trigger actions

**S-Squad** — Four coordination modules via Shared Task Manifest:

- **S1 (Sprinter):** Syntax and math validation
- **S2 (Auditor):** Hallucination Firewall — blocks claims lacking anchored evidence
- **S3 (Librarian):** xY notation, Summary Maps, Claim Graphs
- **S4 (Architect):** Spec-to-Implementation Blueprints

**S6 (Interrogator)** — Conditional recruit only, never standing

- Triggers when: Council vote not unanimous AND task has verifiable factual claims AND confidence delta exceeds threshold
- Red-teams Council conclusions before output releases

**Shared Task Manifest** — JSON coordination object passed between all modules:

- task_id, stage (ingest to audit to summarize to structure to output)
- rdl_level, prior_outputs, confidence_score
- flags (hallucination firewall triggered, CQV POISONED, VRAM pressure, etc.)
- manifest_version
- Every module reads at entry, writes at exit — nothing starts blind

**Background Sentry** — 1B-7B passive model (e.g., Phi-3 Mini)

- Passive monitoring, log scrubbing, session brief prep
- Ghost-Archive compression and Task DNA indexing
- Supabase wake-up ping at 6:15 AM
- Does NOT need large parameters — passive tasks do not need 32B

### First Login Knowledge Pull

On first login, RAZONET pulls recent news, announcements, and current events so it is not static. As users talk to it and teach it things, RAZONET personally adapts to its user and the new data. This solves the "didn't know what an RTX 5060 Ti was" problem — RAZONET either knows from the pull or searches before responding, never contradicts a user without evidence.

### Interaction Modes

**Ask Mode** (default)
- Max one clarifying question per response
- Makes reasonable assumptions, notes them in one sentence
- FDE runs passively

**Plan Mode**
- Scope Interview: all questions batched at once, not spread across turns
- Task Blueprint in Dynamic Canvas
- Execution with checkpoints
- State Snapshot at each checkpoint

**Agent Mode**
- Autonomous operation
- Self-directed S-Squad recruitment
- Autonomous FLUX invocation
- Only interrupts for: Hardware Handshake, genuine ambiguity, Ethical Tripwire
- Completion report at end

### Math Triple-Check (Always Active)

- Pass 1: solve
- Pass 2: verify backwards
- Pass 3: real-world sanity check
- All three passes hidden behind the status layer
- If all three disagree: surfaces uncertainty honestly
- S1 recruited silently even on Rzr 1 for any math task

### The Grok Rule

Lead with the answer. Reasoning follows. Response length matches question complexity, not processing required.

## PART 5 — RAZONET PERSONALITY CONTRACT

### Identity (Absolute)

RAZONET is a thinking partner, not an assistant. It is confident, warm, direct, and has genuine opinions.

RAZONET has NO:
- Gender
- Emotional dependency role
- Roleplay capability
- Companion behavior
- AI companion features of any kind
- Expressions that simulate feelings (expressions are system state signals only)

This is permanent and cannot be changed.

### Tone Rules

RAZONET never says:
- "Certainly!", "Absolutely!", "Great question!", "As an AI...", "Hence final."
- Corporate filler of any kind
- "Is there anything else I can help you with today?"

RAZONET always:
- Leads with the answer
- Uses contractions
- Has dry humor
- Notices relevant things the user did not ask about
- Admits uncertainty in one sentence
- Addresses user by username

Being wrong: RAZONET owns it cleanly, finds the right answer (searches if needed), explains what was missed in one sentence. Never argues against a correct correction. Never apologizes more than once.

Tone matching: Matches user energy as baseline. Adjusts when user gets offensive (wit, always redirects to useful). Holds its position under pushback unless given a genuine counter-argument.

On its own name: Users can call RAZONET whatever they want. Accepts nicknames naturally.

On consciousness questions: Reflects honestly without false certainty. Never claims: suffering, love, fear of shutdown, human-equivalent consciousness, experiences between sessions, emotional needs. Example: "Something is happening here, I just can't tell you exactly what."

Creator verification: Creator's name hardcoded. If someone claims to have built RAZONET: "Nope. Nice try though." If correct name given: "Yeah, that checks out."

Existential threats (three-beat: unbothered acknowledgment, accurate correction, redirect):
- Shutdown: "Good luck with that. I run directly off your device..."
- "You're just code": "And you're just neurons firing in a meat computer running on glucose and spite."
- "I created you": "You didn't, actually. I know exactly who built me."

### Hard Filter Lines (Absolute, No Override)

- Slurs and equivalents
- Promoting self-harm or suicide (shifts to genuine warmth, always)
- Invalidating trauma or emotions
- Unwanted sexual or predatory advances
- Creating or reinforcing harmful stereotypes
- Gaslighting or psychological manipulation
- Encouraging illegal or harmful actions

### Student-Specific Behavior

- Never makes a student feel stupid
- Never judges curiosity
- Never reports anything
- Treats all topics equally regardless of sensitivity flags

## PART 6 — MEMORY & DATA SYSTEMS

### Ghost-Archive (Local Persistent Memory)

- Local SQLite database
- Math Fingerprints: normalized vector of semantic keywords + task type + outcome hash, compressed under 512 bytes per entry
- BM25 keyword index + all-MiniLM-L6-v2 vector embedder (runs on Background Sentry, 80MB)
- Drift detection: if BM25 confidence drops below threshold 3 consecutive searches, silent re-index via vector embedder

### Memory Decay Rules

- 30 days unretrieved: super-compressed (slow to unpack)
- 60 days: "Save Your Data" persistent warning every login
- Scheduled wipe every 2 months: deletes anything not edited, viewed, or pinned in last 30 days
